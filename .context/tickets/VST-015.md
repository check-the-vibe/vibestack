## Outcome and scope

Replace the full-page chat-shell proposal with a small agent icon over the working desktop canvas. Clicking opens the chat panel; closing preserves work and releases input to the desktop. Implement a deterministic provider selection/install/launch/sign-in flow before an LLM is available. Bind conversations to the selected runtime, stream real events/results and surface secure human approvals. Use catalog/adapter data rather than vendor logic in the UI.
