## Outcome and scope

Apply the shared operation contract to built-in and extension capabilities across clients with consistent grant enforcement, error behavior, file preconditions, limits and retries. Preserve supported v1 clients. Trace the shared capability matrix across CLI, REST, MCP and web services, using the real SPEC-003 MCP adapter and an authenticated browser HTTP client (chat UI is not a prerequisite); do not claim parity from documentation or mocks alone.
