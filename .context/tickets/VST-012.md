## Outcome and scope

Expose registered built-in and user-authored workspace capabilities through the shared dispatcher. Add a thin local stdio bridge for clients that need it, using the same protected HTTP service and credentials. Host tools remain in the separate existing runner; no new Docker authority or policy engine.
