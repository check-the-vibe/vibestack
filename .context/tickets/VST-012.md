## Outcome and scope

Expose registered built-in and user-authored workspace capabilities through the shared dispatcher. Add a thin local stdio bridge for clients that need it, using the same protected HTTP service and credentials. Host tools remain in the separate existing runner; no new Docker authority or policy engine.

## Evidence

The reviewed VST-011/VST-017 stack is incorporated through parent `f609ebb`.
Parent private-gateway acceptance is still pending its credential-use approval.

- 31 compiled workspace adapters preserve operation IDs and map only to fixed
  local backends. Together with `project_summary`, 26 tools are eligible for MCP;
  grants further filter that set. Clipboard, SSH keys and client administration
  remain excluded. Password/pairing operations and host tools are not registered.
- Registered REST and MCP share input validation, authorization and dispatch.
  Existing raw/friendly REST response formats remain compatible. Binary JSON
  transfers are capped at 8 MiB before base64; conditional file writes require an
  observed strong ETag or create-only condition. Backend errors are sanitized and
  uncertain mutations are never automatically replayed.
- The source-built `vibestack mcp` bridges actual stdio to the selected workspace,
  pins identity and refreshes remote tool lists. Profile/gateway files are opened
  without following links, checked on their open descriptors and read boundedly.
  Only protocol frames use stdout. No ambient GitHub token is read.
- Source gate: 319 Python tests, all Go packages and 3 JavaScript tests passed.
  Logs `/tmp/vst-012-source.log` and final helper/metadata rerun
  `/tmp/vst-012-source-final.log`. Race checks passed for service, registry and
  client packages (`/tmp/vst-012-race.log`). 291 relative documentation links passed.
- CLI builds passed on Linux/macOS, amd64/arm64. Temporary worktree builds needed
  `-buildvcs=false` because a protected `/tmp/.git` marker is not a repository;
  it was preserved. This does not claim execution on the other three targets.
- Candidate `vibestack:vst-012-workspace-tools-20260921`, image index
