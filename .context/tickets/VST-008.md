## Outcome and scope

Audit actual operations and define the small capability registration, route/CLI mapping, authentication context, errors, versions and per-operation retry contract. Map every capability across CLI, REST, authenticated MCP and web services with shared authorization/semantics and explicit unavailable or human-handoff states. Use one harmless extension to validate the proposed shape. This is a contract task; it does not require a broker or deployment.
