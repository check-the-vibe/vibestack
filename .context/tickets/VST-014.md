## Outcome and scope

Implement the supported provider catalog and authenticated activate/status/stop/open-app operations inside the existing workspace service. Reuse the catalog installers and persistence for Codex and OpenCode, manage their in-VibeStack processes, and build tested API adapters for conversations, events, approvals and interrupts. The provider owns its agent loop; VibeStack does not replace it with another model loop. Installation, process, login and readiness states remain distinct.
