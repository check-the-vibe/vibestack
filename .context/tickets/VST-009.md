  legacy commands, bounded file/stdin inputs, exact integer results and no mutation
  replay. Direct workspace profiles pin instance identity. Scoped token connect
  checks the current authenticated catalog before writing a protected profile.

  read fresh on each request, and kept separate from the workspace credential.

  rotation, wrong destinations, unsafe files, login redirects and no ambient-token
  fallback. Outside private-gateway acceptance still requires the pending approval.

  assets, SHA-256 and GitHub Actions build attestations. The installer defaults to

  documented. Current v1 aliases remain; historical 0.2 authentication migration
  remains explicit. No anonymous or OAuth-only external compatibility is claimed.
