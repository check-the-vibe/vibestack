## Outcome and scope

Mount MCP on the same workspace service origin/process and authentication middleware as REST. Verify configured bearer access with supporting clients; integrate a standard authorization server for selected clients requiring OAuth discovery/consent. Reuse protected internal backend credentials instead of passing external tokens downstream. No separate broker or auth server implementation.
