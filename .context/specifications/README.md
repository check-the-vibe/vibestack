# Feature specifications

Create `SPEC-NNN-short-name.md` from [the template](../templates/specification.md)
using [the specification prompt](../prompts/specify.md). Each specification owns
its acceptance criteria and linked ticket plan. Execution state belongs in the
tickets, not a duplicate status table here.

The [initiative queue](../initiatives/agent-platform.md) reserves SPEC-001 through
SPEC-004. Those feature specifications will be written next; they are not yet
implemented or ready for development.
