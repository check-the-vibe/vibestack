# Runner operations source

Fetch the version-matched reference with `vibestack --profile NAME docs runner`.
Remote agents may use only approved templates and managed lifecycle fields.

Discovery advertises paired or trusted-tailnet authentication and the private
`/mcp` endpoint. Trusted callers share all managed resources. Use explicit
instance IDs for workspace tools, poll durable operation/job IDs, and hand off
password setup to the human. The harness itself needs tailnet connectivity.
