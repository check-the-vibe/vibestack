# VibeStack 0.3.1

This patch bounds MCP request identifiers in the native stdio bridge and the
workspace HTTP endpoint. Encoded identifiers are limited to 256 bytes, frames
to 24 MiB, and tool results leave room for their JSON-RPC wrapper. Oversized
identifiers fail before a workspace handler runs.

The workspace service also rejects duplicate JSON input keys consistently and
returns the shared grant/unknown-tool errors through MCP. nginx explicitly
disables upstream retries for authenticated API and MCP requests.

Real fault-injection coverage exercises dropped accepted command replies through
HTTP MCP, CLI stdio and generic CLI; partial responses; explicit cancellation;
duplicate submissions; conditional writes; and bounded output. The optional
rollback gate changes candidate → previous accepted image → candidate using
disposable persistent volumes. Historical source-built 0.2 clients and current
clients exercise the unchanged private runner in both supported authority modes.

An uncertain reply never proves that work was cancelled. Inspect remote state
before resubmitting a mutation. Existing 0.3.0 CLI profiles remain compatible;
upgrading to 0.3.1 adds the local identifier guard. Private Codespaces gateway
authentication remains separate from the workspace credential. OAuth-only
harnesses remain unsupported by this bearer/stdio configuration.

Native Linux/macOS amd64/arm64 artifacts, checksums, installer and provenance are
produced by the release workflow. Publication is complete only when that workflow
and the release's public asset checks have succeeded; see VST-013 for evidence.
